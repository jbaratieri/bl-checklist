Bypass local (somente desenvolvimento)

Setup (uma vez por máquina): copie este arquivo para dev-bypass.html na mesma pasta (dev/dev-bypass.html). Esse nome está no .gitignore, então o deploy.ps1 não envia para o Git público. No PowerShell, na raiz do projeto: Copy-Item dev\dev-bypass.example.html dev\dev-bypass.html

Abra pela mesma origem do app (ex.: http://localhost:…/dev/dev-bypass.html). file:// usa outro localStorage e não funciona com o app.

A pasta dev/ está fora do deploy na Vercel (.vercelignore).
